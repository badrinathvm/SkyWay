CarPlay scene lifecycle

How and when iOS calls CarPlaySceneDelegate in Skyway, from install to unplugging from the car.

1

The app is installed

  • Info.plist declares a CPTemplateApplicationSceneSessionRoleApplication scene whose delegate class is CarPlaySceneDelegate.
  • The com.apple.developer.carplay-driving-task entitlement allows Skyway in CarPlay.
2

The iPhone connects to the car

  • USB or wireless. The Skyway icon appears on the car's Home screen.

None of your code has run yet.

Driver taps the Skyway icon
3

iOS starts the CarPlay scene

  • Launches the app process if it isn't running, even with the iPhone locked and no iPhone UI.
  • Creates a CPTemplateApplicationScene.
  • Creates a CarPlaySceneDelegate, using the class name from Info.plist.
4

templateApplicationScene(_:didConnect:)

Delegate call
  • Keeps the CPInterfaceController and the scene.
  • Builds the Trip, Airport, and Checklist tabs.
  • Calls setRootTemplate(tabBar), and the car screen shows Skyway.
  • Starts the 30-second refresh timer.

A root template must be set before this method returns, or the car screen stays blank.

5

While connected, closures run on events

EventCode that runs
Taps Directions on the Trip tabopenDirections(to:) opens Maps
Taps Airport OptionstabBar.select(airportTemplate)
Taps the Boarding pass rowshowBoardingPass() pushes a template
Taps Directions on an airport spotopenDirections(to: spot)
Moves the mappointOfInterestTemplate(_:didChangeMapRegion:) (no-op)
Every 30 secondsrefreshTripItems() updates the countdown

Switching to another CarPlay app only backgrounds the scene. Skyway stays connected, and coming back doesn't call didConnect again.

The car disconnects: unplugged, car off, or scene discarded
6

templateApplicationScene(_:didDisconnectInterfaceController:)

Delegate call
  • Stops the timer.
  • Sets the interface controller, scene, and templates to nil.

↻ The next connection starts again at step 2, with a fresh delegate.

Takeaways

  • Either screen can run without the other. The app can launch for CarPlay alone, with the iPhone locked. The two scenes never talk directly; both read from TripStore, so app data lives in the model, not in views.
  • There's no separate CarPlay target. CarPlay is part of the Skyway iOS app target.
  • Nothing in CarPlay redraws on its own. To change what's on screen, replace a template's contents, as refreshTripItems() does by setting tripTemplate.items.
See App/CarPlaySceneDelegate.swift for the implementation.
